# AYLENSALE — план QA (Desktop → Tablet → Mobile)

Порядок: **сначала комп + админка**, потом **планшет**, потом **телефон**. После каждого блока — скриншот и галочка в отчёте.

## Подготовка

1. Деплой: `./scripts/deploy-prod.sh` или локально `npm run build` + сервер из `public/`
2. Жёсткое обновление: Cmd+Shift+R
3. Вход в админку: **Cmd+Shift+A** → пароль (тот же, что `ADMIN_PASSWORD` на Vercel для Branding API)

---

## Фаза A — Desktop (≥1280px)

| # | Раздел | Проверка | Ожидание |
|---|--------|----------|----------|
| A1 | Header | Card #, билет+Code, eBay, корзина, ключ | В одну линию, без налезания |
| A2 | Hero | Кнопки, статистика | Читаемо, без белой вспышки |
| A3 | Products | Сетка, цена, описание 2 строки | Компактные карточки, не «башни» 300px |
| A4 | Products | Add to cart, фильтры, поиск | Работает, счётчик корзины в шапке |
| A5 | Auctions | Карточки, bid | Открывается, без обрезки |
| A6 | Pickup | Горизонтальный скролл, зелёная/серая карточка | GOING зелёный, остальные серые |
| A7 | Pickup | Погода | Saturday/Sunday по дню в админке, иконка FA, °C, % дождя |
| A8 | Footer | Прокрутка до низа | Виден футер, нет «залипшего» overflow |
| A9 | Bottom nav | Нет Cart | Только Products / Auctions / Pickup (+ TG/WA на широком) |

### Админка (Desktop)

| # | Панель | Действие | Синхронизация |
|---|--------|----------|----------------|
| B1 | Products | + Product, фото, Save | Появляется на витрине |
| B2 | Products | Edit, Delete | Обновление сетки |
| B3 | Pickup | + Location, день Sat/Sun, postcode, фото | Карточка + погода |
| B4 | Pickup | Edit, Set GOING / Grey | Цвет карточки |
| B5 | Auctions | Add / Edit / Delete | Секция auctions |
| B6 | Discounts | Код + Card # в шапке | Скидка в цене |
| B7 | Branding | Upload → Preview → Save | Favicon / PWA (нужен пароль в сессии) |
| B8 | Settings | eBay URL, контакты | Шапка / футер |
| B9 | Выход CMS | Esc / Close | Витрина снова скроллится, товары на месте |

## Фаза B — Tablet (768–1024px)

Повторить **A1–A9** (витрина) и выборочно **B3–B4** (pickup modal на планшете).

| # | Особое |
|---|--------|
| C1 | Нижнее меню: 3 колонки, без Cart |
| C2 | Pickup modal: форма прокручивается внутри |
| C3 | Products: 2–3 колонки, карточки одной высоты по ряду |
