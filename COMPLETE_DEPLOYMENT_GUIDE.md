### ШАГИ 4-5: Подключение к Vercel

**Способ 1: Прямо из Vercel Dashboard**

1. Откройте https://vercel.com/dashboard
2. Нажмите **Add New** → **Project**
3. Нажмите **Import Git Repository**
4. Введите: `https://github.com/999Oleh/aylensale-si`
5. Нажмите **Import**
6. Vercel автоматически определит Next.js приложение
7. Нажмите **Deploy** (или **Continue** → **Deploy**)

**Способ 2: Через Vercel CLI (если у вас установлен)**

```bash
npm install -g vercel
vercel link
vercel deploy --prod
```

### ШАГ 7: Как получить CHAT_ID для Telegram

1. **Отправьте сообщение боту**:

   - Найдите бота: `@aylensale_bot` или `@your_bot_name`
   - Отправьте любое сообщение (например: "hi")

2. **Получите Chat ID**:
   - Откройте в браузере эту ссылку:
   ```
   https://api.telegram.org/bot8755212472:AAGlOOBDtFfE5JKXbQubw1T9BQm_0ctiEXY/getUpdates
   ```
   - Найдите в ответе строку: `"chat":{"id":XXXXXXXXXXXXX}`
   - Скопируйте это число (XXXXXXXXXXXXX)

3. **Добавьте в Vercel**:
   - В переменную `NEXT_PUBLIC_TELEGRAM_CHAT_ID` вставьте это число

## 🔧 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

### Telegram уведомления не приходят
1. ✅ Проверьте, что CHAT_ID правильный (см. выше как получить)
2. ✅ Проверьте, что TOKEN правильный
3. ✅ Откройте ссылку в браузере:
   ```
   https://api.telegram.org/bot8755212472:AAGlOOBDtFfE5JKXbQubw1T9BQm_0ctiEXY/sendMessage?chat_id=[ВАШ CHAT_ID]&text=Test
   ```
   - Если приходит `{"ok":true}` — значит всё работает
   - Если нет — значит CHAT_ID неправильный

### Фото не загружаются
1. ✅ Проверьте, что Cloudinary конфиг правильный
2. ✅ Проверьте интернет-соединение
3. ✅ Откройте DevTools (F12) → Console и посмотрите ошибки

### Админка не открывается
1. ✅ Проверьте пароль (должен быть: `aylen2026`)
2. ✅ Откройте DevTools (F12) → Console и посмотрите ошибки
3. ✅ Очистите браузер-кеш (Cmd+Shift+Delete на Mac)

### Карта не отображается
1. ✅ Проверьте интернет-соединение
2. ✅ Проверьте, что Leaflet CSS загружается (DevTools → Network)
3. ✅ Откройте DevTools → Console и посмотрите ошибки
