# Переменные окружения Vercel (Production + Preview)

| Переменная | Описание |
|------------|----------|
| `NEXT_PUBLIC_FIREBASE_API_KEY` | Firebase Web API key |
| `NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN` | `aylensale.firebaseapp.com` |
| `NEXT_PUBLIC_FIREBASE_PROJECT_ID` | `aylensale` |
| `NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET` | `aylensale.firebasestorage.app` |
| `NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID` | из Firebase Console |
| `NEXT_PUBLIC_FIREBASE_APP_ID` | из Firebase Console |
| `ADMIN_PASSWORD` | пароль админ-панели (только сервер) |
| `TELEGRAM_BOT_TOKEN` | новый токен от @BotFather |
| `TELEGRAM_CHAT_ID` | ID чата для заказов |

После смены токена Telegram перевыпустите бот в BotFather — старый считайте скомпрометированным.
