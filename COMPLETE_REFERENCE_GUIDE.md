## 📸 ФОТОГРАФИИ - ТЕХСПЕКИ

### **Поддерживаемые форматы:**
- JPG ✅
- PNG ✅
- GIF ✅
- WebP ✅

### **Ограничения:**
- Макс 10 фото на товар
- Макс 5MB на одно фото
- Общий максимум на товар: 50MB

### **Хранилище:**
- **Первичное:** Cloudinary (облачное)
- **Резервное:** Base64 (если Cloudinary недоступна)

### **Процесс загрузки:**
```
Вы выбираете файл
    ↓
Система пытается загрузить на Cloudinary
    ↓
Если успешно → фото на облаке (CDN)
    ↓
Если ошибка → автоматически конвертируется в Base64 и сохраняется локально
```

## ⚠️ ПОТЕНЦИАЛЬНЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ

### **Проблема 1: Ctrl+Shift+A не работает**
```
Причины:
- Окно браузера не в фокусе
- На Mac может быть Cmd+Shift+A
- Ошибка в раскладке клавиатуры

Решения:
1. Кликните на окно браузера
2. Попробуйте ⌘+Shift+A (если Mac)
3. Переключите раскладку на English
4. Перезагрузите страницу
5. Используйте triple-tap вместо этого
```

### **Проблема 2: Фотографии не загружаются**
```
Причины:
- Размер файла > 5MB
- Неправильный формат (например, TIFF)
- Проблема с интернетом
- Cloudinary временно недоступна

Решения:
1. Проверьте размер файла (Properties)
2. Конвертируйте в JPG или PNG
3. Проверьте интернет соединение
4. Подождите минуту и попробуйте еще раз
5. System автоматически использует Base64 как резервный вариант
```

### **Проблема 3: Заказы не приходят в Telegram**
```
Причины:
- Не подписаны на бота @aylensale_bot
- Интернет проблема на сайте
- Telegram API временно недоступна

Решения:
1. Откройте Telegram, найдите @aylensale_bot
2. Нажмите /start или отправьте сообщение
3. Проверьте интернет на сайте
4. Обновите страницу (F5)
5. Попробуйте сделать новый заказ
```

### **Проблема 4: Админ панель медленная**
```
Причины:
- Много фотографий загружено
- Медленный интернет
- Браузер перегружен вкладками

Решения:
1. Закройте ненужные вкладки
2. Очистите кэш браузера (Ctrl+Shift+Delete)
3. Перезагрузите страницу
4. Перезагрузите браузер
5. Используйте Chrome или Safari для лучшей производительности
```
