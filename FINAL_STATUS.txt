⚡ TROUBLESHOOTING

If Ctrl+Shift+A doesn't work:
   1. Click on browser window
   2. Reload page (⌘+R or F5)
   3. Try ⌘+Shift+A (Mac) instead
   4. Use mobile method (triple-tap)

If photos don't upload:
   1. Check file size (< 5MB)
   2. Check format (JPG/PNG/GIF/WebP)
   3. Check internet connection
   4. System uses Base64 as backup

If orders don't come to Telegram:
   1. Open Telegram app
   2. Find @aylensale_bot and tap /start
   3. Try making order again
   4. Check internet connection
