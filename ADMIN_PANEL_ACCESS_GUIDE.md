### Почему так?
```
aylensale-si (Next.js) → www.aylensale.com
    ↓
  HTML/CSS/JS статика, NO админ скрипты

car-sales-uk (статика) → https://car-sales-uk.vercel.app
    ↓
  Содержит admin.js, photo-upload.js, cloudinary-config.js
  Полностью функциональный проект ✅
```

## 📱 ФУНКЦИИ АДМИН ПАНЕЛИ

### **Доступные операции:**
- ✅ **+ Product** - Добавить новый товар
  - Название, описание

  - Координаты на карте

- Убедитесь что Cmd не зарезервирована системой
- Используйте мобильный способ (triple-tap) вместо этого
