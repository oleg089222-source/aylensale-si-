## ⚠️ ВОЗМОЖНЫЕ ПРОБЛЕМЫ

### **Если Ctrl+Shift+A не работает:**
```
1. Кликните на окно браузера
2. Перезагрузите страницу (⌘+R)
3. На Mac попробуйте Cmd+Shift+A
4. Используйте mobile метод (triple-tap)
5. Убедитесь что на сайте https://car-sales-uk.vercel.app
```

### **Если фото не загружаются:**
```
1. Проверьте размер (макс 5MB)
2. Проверьте формат (JPG/PNG/GIF/WebP)
3. Проверьте интернет
4. System автоматически использует Base64
```

### **Если заказы не приходят в Telegram:**
```
1. Откройте Telegram
2. Найдите @aylensale_bot и нажмите /start
3. Попробуйте заказ еще раз
4. Проверьте интернет
```
